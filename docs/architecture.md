# 00 · 这个文件夹是什么（总览）

> 位置：`D:\桌面\dafeiyu\dsh-pet-data`
> 日期：2026-11-07
> 一句话：**桌宠「小鱼 / 鲸娘」的全部数据、脚本、素材、模型都在这里。**

---

## 一、先记住三句话

1. **不要随便改名或删除这里的文件** —— 很多文件名被代码写死，改名等于功能失效。
2. **上面有两个「链接」指向这里**，删了链接（junction）会连带断掉：
   - `C:\Users\Chinagay\.dsh\dsh-pet` → 指向 `dsh-pet-config`
   - `D:\dsh-tools` → 指向 `dsh-tools`
3. **想改任何东西之前，先看本目录的 01 / 02 / 03 清单**，确认这个文件是干什么的。

## 二、顶层目录一览

| 目录 | 大小 | 干什么的 | 能不能删 |
|---|---|---|---|
| `corpus` | 5.6 MB | **记忆库**：聊天记录、事实、日志 | ❌ 绝对不能 |
| `songs` | 5.1 MB | **曲库**：歌曲信息、歌词、播放记录、喜好榜 | ❌ 不能 |
| `config` | 很小 | 配置快照（main-config / voice） | ⚠️ 可删，但会丢历史快照 |
| `dsh-pet-config` | 0.1 MB | 桌宠主配置（人设、模型设置） | ❌ 不能 |
| `dsh-tools` | 12 MB | **所有脚本**（语音、歌曲、备份、调优） | ❌ 不能 |
| `backup` | 5.6 MB | 自动备份（配置 + 记忆 + 事实） | ⚠️ 超过 7 天的可删 |
| `models` | 7.7 GB | Ollama 大模型（3B / 7B / 向量） | ⚠️ 能重下，但很慢 |
| `voice-cache` | 15 MB | **她说过的话的音频缓存**（mp3） | ⚠️ 可删，删了要重新合成 |
| `voice-experiments` | 369 MB | 拼接连发语音的实验素材（音节/词/句） | ⚠️ 可删，是实验品 |
| `plugins` | 75 MB | 开机动画等小插件 | ⚠️ 看情况 |
| `vendor` | 64 MB | 插件补丁备份（dsh-pet-0.3.8-patched） | ⚠️ 建议留着 |
| `tools` | 2.0 GB | 开发工具、gguf 模型、安装包 | ⚠️ 大部分能删 |
| `logs` | 1.4 MB | 下载/拉取日志 | ✅ 可以删 |
| `inbox` | 空 | 语音待合成队列（临时） | ✅ 空了就没事 |
| `按钮` | 很小 | 24 个快捷方式（双击执行常用操作） | ❌ 不能（你天天用） |
| `说明文档` | 本目录 | 你看的这份说明 | ❌ 留着 |

## 三、数据是怎么流动的（一张图）

```
你说话
  ↓
voice-chat.py（听，识别）
  ↓
DSH 插件 dsh-pet（思考）
  ↓
Ollama 模型（3B 小鱼 / 7B 鲸娘）
  ↓
voice_daemon.py（合成语音 + 播放）
  ↓
voice-cache/*.mp3（缓存）
  ↓
记录写进 corpus/speech.jsonl 和 corpus/memory.jsonl
```

## 四、两个「人格」的区别

| 项目 | 小鱼（第一人格） | 鲸娘（第二人格） |
|---|---|---|
| 模型 | pet-brain（3B） | qwen2.5:7b-instruct |
| 音色 | `efc1ce37…` | `325afed0…` |
| 唤醒 | 一直在线 | 「鲸娘」/「叫那个姐姐出来」 |
| 切回 | —— | 「让小鱼出来吧」 |
| 记忆 | 只看自己那段 | 全知道（含小鱼那段，带标注） |
| 人设文件 | `dsh-pet-config\main-config.jsonc` | 同文件（但代码里有独立提示词） |

**人格状态存在**：`persona.json`（根目录）
