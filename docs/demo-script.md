# 演示视频脚本（5–8 分钟，含 2 分钟 AI 协作展示）

> 比赛要求：5–8 分钟 MP4 1080p，其中至少 2 分钟「AI 协同过程复现展示」（录屏里展示输入某段 Prompt 让 AI 生成核心模块，或如何引导 AI 修 Bug）。

## 0:00–0:40 开场

- 画面：桌面宠物在桌面走动、说话气泡
- 旁白：这是一个跑在 DSH 上的本地桌宠，双人格、可语音对话、记得住事、只认主人的声音。

## 0:40–2:00 功能演示

| 时间 | 操作 | 期望画面 |
|---|---|---|
| 0:40 | 说「小鱼，今天好累」 | 气泡出现识别文字 → 她回答 + 语音 |
| 1:10 | 说「鲸娘」 | 播「女仆屈膝礼仪」，鲸娘音色开场 |
| 1:30 | 说「小鱼就会说好听的，你还不如小鱼」 | 鲸娘傲娇、吃醋、学小鱼语气 |
| 1:50 | 说「让小鱼出来吧」 | 鲸娘告别 → 小憩动画 → 小鱼开场白 |

## 2:00–3:00 记忆与单向可见

- 切到鲸娘问「刚才小鱼跟你说了什么」→ 她能说出来
- 切回小鱼问「鲸娘刚才说了什么」→ 她不知道（失忆）
- 打开 `memory.jsonl` 展示 `who` 字段

## 3:00–4:00 语音输入细节

- 按 F9，喊「小鱼」，边说边看气泡逐字出现（流式识别）
- 让旁人喊「小鱼」→ 日志显示「不是主人的声音，忽略」

## 4:00–6:00 AI 协作复现（重点，录屏）

选两个片段，真实操作给评委看：

### 片段 A：让 AI 实现「时间块按需注入」

1. 打开 DSH 对话窗口，原样输入 Prompt：
   > 「时间块那里我想，只有我问到和时间相关的话题时，她才去看一眼时间，其它时候直接不看（这里应该能用代码实现，不需要提示词）。然后顺序是：人设 → 关系 → 事实 → 记忆 → 时间 → 提示。」
2. 展示 AI 返回的代码改动（diff）
3. 重启后展示日志：普通闲聊 `手表 0`；说「我头疼」`手表 85`
4. 展示效果：首块时间从 16.8s 降到 6.8s

### 片段 B：引导 AI 修「气泡不出现」

1. Prompt：
   > 「框还是没弹啊……我不知道强制刷新页面是在哪里刷新」
2. 展示 AI 定位过程：CURL 访问 `/voice-draft` 返回 500 → 发现路由少了 `kind:"json"` → 修复
3. 展示修复后气泡出现

## 6:00–7:00 架构与约束

- 打开 `docs/architecture.md`，讲三层：宿主插件 / 语音助手 / 本地模型
- 讲约束策略：提示词顺序设计、按需注入、复读阈值按人格+长度、流式线程隔离

## 7:00–7:30 收尾

- 数据面板：提示词字数、首块延迟、识别延迟对比表
- 说明局限：7B CPU 推理上限、声纹误判场景

## 录制建议

- 用 OBS 录 1080p；麦克风与系统声分开轨
- 打字过程保留（体现真实操作），后期 1.5 倍速
- 日志窗口单独录制一小段，便于看清关键行
