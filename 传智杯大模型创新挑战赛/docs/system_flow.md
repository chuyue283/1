# 系统流程说明

## 语音唤醒流程

1. 麦克风持续采集，VAD 判断一句话是否说完。
2. 声纹比对，不是主人的声音直接丢弃。
3. 识别文字，命中唤醒词后进入对话状态。
4. 桌宠回应一声，开始等待下一句。

## 普通对话流程

1. 语音或文字进入桌宠。
2. 代码先做意图拦截：切换人格、唱歌、算数、时间。
3. 未命中则拼装提示词：人设、事实、记忆、时间、防复读。
4. 本地模型流式生成，边生成边按句合成播放。
5. 生成后判断是否答非所问，必要时补一句。
6. 这一轮写入记忆。

## 双人格切换流程

1. 识别到切换词。
2. 播放出场动画，切换模型与音色。
3. 用当前人格的开场白打招呼。
4. 切回小鱼时，小岚先说一句告别，再切回。

## 长篇写作流程

1. 识别到写日记、情书、故事的意图。
2. 检索最近几天的真实记忆作为素材。
3. 允许长段落，循环播放写作动画。
4. 攒够若干句后开始逐句朗读，气泡同步变长。
5. 写完后全文存入 longform.jsonl，普通记忆只留摘要。

## 记忆固化流程

1. 每天把当天对话按重要性取前几条。
2. 生成一条“今日印象”，衰减更慢。
3. 写日记或回忆时，这些印象一起进入提示词。
