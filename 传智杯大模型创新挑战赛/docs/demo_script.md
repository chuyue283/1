# 比赛演示脚本

## 演示流程

1. 桌面展示角色，说明这是一个常驻桌面的本地 AI，不是网页问答。
2. 按 F9 唤醒，说一句日常话，展示语音识别与回答。
3. 说「小岚」，展示切换动画、音色变化与开场白。
4. 问小岚「小鱼刚才说了什么」，展示单向记忆。
5. 说「让小鱼出来吧」，展示告别与切回。
6. 说「写一篇关于我们之间的日记」，展示长篇模式：动作、气泡变长、边写边念。
7. 写完后问「把你刚才写的念给我听」，展示长篇存档与回忆。
8. 让旁人喊一声「小鱼」，展示声纹过滤，日志显示“不是主人的声音”。
9. 打开 host.log，展示提示词长度、首块时间、记忆打分与好感度日志。
10. 总结：双人格、记忆、语音、长篇写作与工程可靠性。

## 演示提示

- 先演示短对话，再演示长篇，节奏更清楚。
- 声纹过滤建议现场让旁人配合，效果直观。
- 日志窗口单独放一块屏幕，方便评委看到数据。
- 如果网络不稳，提前把 Fish 语音缓存预热一遍。
