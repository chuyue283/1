# 组件架构说明

## 人格引擎

- 维护当前人格（小鱼 / 小岚）与切换状态
- 用代码拦截切换词，不经过模型
- 每个人格独立的模型、音色、说话规则与开场白

## 记忆系统

- 每条记忆记录时间、说话人、内容、重要性、被想起次数
- 分层：最近对话、向量检索、时间检索、每日印象
- 单向可见：小岚能看全部，小鱼只看自己
- 长篇作品单独存入 longform.jsonl，不占普通记忆

## 语音输入

- 录音分块、VAD 断句
- 流式识别出草稿，精修后发送
- 声纹比对，非主人直接忽略

## 语音输出

- 发声进程负责合成、缓存、解码、播放
- 按人格切换音色
- 开机问候与背景音乐配合

## 意图拦截

- 切换人格、唱歌、算数、时间、年龄由代码处理
- 不交给小模型判断，保证准确与速度

## 长篇写作

- 识别写日记/情书/故事的意图
- 允许长段落，边写边念
- 写完后全文单独存档，可再次朗读

## 自我纠错

- 第一句播出后后台判断是否答非所问
- 没答到就补一句，只补一次
